# Not Yet Built

A scrolling, animated explainer on five machines nobody has built: ocean-cleaning zeppelins, electrogravitic engines, personal ion transport, haptic holograms (whisps) and chip-skinned drone swarms.

One file, no dependencies. Open `index.html` and scroll. The ion chapter has a working bench: exhaust speed, thrust and power use the real ion-drive equations (v = √(2qV/m), T = I·√(2mV/q)).
